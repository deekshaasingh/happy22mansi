PUT YOUR SONG HERE
==================

1. Rename your music file to exactly:   song.mp3
2. Drop it in this  audio/  folder  (so the path is  audio/song.mp3 )
3. That's it. The site plays it automatically after "Enter The Theatre".

Notes
-----
- .mp3 is the safest format (works on every phone + browser). .m4a or .ogg also work
  if you rename the file to song.mp3 is not possible — in that case open index.html,
  find  musicFile: "audio/song.mp3"  and change it to your filename.
- The music NEVER autoplays before the visitor clicks "Enter The Theatre" (on purpose).
- If you don't add a song, the site still works perfectly — it just stays silent, and all
  the little click/sparkle sound effects still play.
- Keep the file reasonably small (under ~8 MB) so it loads fast on mobile data.
- Use a song you have the right to use (your own file, or a legal/licensed source).
